# Linha de base — as skills funcionam?

Registro do que aconteceu em uso real. Uma entrada por observação.

**O que vale registrar:** o prompt exato, a skill que entrou, e a evidência de
que foi a skill e não conhecimento genérico do modelo. Sem a terceira coluna a
entrada não serve — "funcionou" sem prova é torcida.

**As três coisas que podem dar errado**, e cada uma conserta de um jeito:

| Caso | O que conserta |
|---|---|
| não disparou | a `description` — por isso o prompt exato é obrigatório |
| disparou e a regra foi ignorada | o texto da skill, que não está afirmativo o bastante |
| disparou onde não devia | a `description`, estreitando |
